# Changelog

## v0.1.0 – pre-release (November 2026)

First public version. Tested in dry-run mode only.

- Solar surplus controller blueprint: three presets, time window, price ceiling and spike cut-off, negative-price boost, optional cheap-grid running, pool pump interlock, minimum run/rest times, dry run.
- Optional meter freshness check: stops the heat pump if the energy meter freezes while still showing its last values.
- Helper package: switches, thresholds, window, last-decision text, solar surplus sensor and a defaults script.
- Pool cover sunset reminder blueprint.
- Pool heating dashboard card.
